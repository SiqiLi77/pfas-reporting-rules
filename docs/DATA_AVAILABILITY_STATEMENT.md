# Suggested manuscript statement

## V2.06 (release v1.1.0)

UCMR 3 and UCMR 5 occurrence data, SDWIS data, American Community Survey tables and U.S. Drought Monitor indices are publicly available from the sources listed in Text S11. Analysis scripts, outputs and figure source data accompany the Supporting Information and are public as release v1.1.0 of https://github.com/SiqiLi77/pfas-reporting-rules; code for Texts S1–S10 and R1–R10 is in release v1.0.0 of the same repository.

## V1.59 (release v1.0.0)

The UCMR occurrence archives are publicly available from the U.S. Environmental Protection Agency. Washington water-quality records are available through the Washington State Department of Health Sentry Internet database, and West Virginia finished-water records through the USGS data release (https://doi.org/10.5066/P13ZNTD3). Analysis code, derived data, frozen prediction distributions, and the numerical data underlying the figures and tables are available at https://github.com/SiqiLi77/pfas-reporting-rules, release v1.0.0. The repository documents source versions, analysis populations, weighting schemes, file checksums, and reproduction instructions. Frozen-result replay is distinguished from model retraining; the original marginal-model checkpoints are not included.
